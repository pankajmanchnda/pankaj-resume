# Pankaj Manchanda Resume Site

This is a free static resume website designed for GitHub Pages, Netlify, or Vercel.

## How to edit quickly

Most resume content lives in `resume.json`.

Open the site with:

```text
http://localhost:8000/?edit=1
```

Then update the JSON, preview the change, and export the updated `resume.json`.

## How to publish for free

### GitHub Pages

1. Create a public GitHub repository named `pankaj-resume` or `yourusername.github.io`.
2. Upload these files.
3. In GitHub, go to **Settings > Pages**.
4. Choose the `main` branch and root folder.
5. GitHub gives you a free public URL.

### Netlify or Vercel

Import the GitHub repository and deploy it as a static site. No build command is needed.
